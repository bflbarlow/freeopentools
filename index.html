There is no server

Every tool runs entirely in your browser. Your data never leaves your machine — nothing is uploaded, stored, or processed remotely.

No account. No cookies.

Open a tool and start using it. No sign-up, no login, no tracking, no data collection. Ever.

Free and open source

About

Free Open Tools is built by Benjamin Barlow — a developer who believes web tools should be simple, transparent, and free. Every tool here runs entirely in your browser with no server, no account, no tracking. The code for each tool is open source and available on GitHub.
